# escrow

A token escrow contract for Soroban, generated by
[soroban-forge](https://github.com/soroban-forge-labs/soroban-forge) from the
`escrow` template.

## Features

- **deposit** — depositor locks funds into the contract
- **approve_release** — designated approver releases funds to the recipient
- **refund_on_timeout** — after the timeout ledger sequence, anyone can trigger
  a refund back to the depositor
- Clean state machine: `Pending → Funded → Released | Refunded`

## Develop

```sh
cargo test                 # run unit tests
stellar contract build     # build the deployable wasm
```

## Deploy to testnet

```sh
stellar contract deploy \
  --wasm target/wasm32v1-none/release/escrow.wasm \
  --source-account <your-identity> \
  --network testnet
```

See the [Stellar docs](https://developers.stellar.org/docs/build/smart-contracts)
for the full workflow.
