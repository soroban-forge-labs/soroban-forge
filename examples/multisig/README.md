# multisig

An M-of-N multisig account contract, generated by
[soroban-forge](https://github.com/soroban-forge-labs/soroban-forge) from the
`multisig` template. Based on the official custom-account example in
[stellar/soroban-examples](https://github.com/stellar/soroban-examples).

The contract implements `soroban_sdk::auth::CustomAccountInterface`, so its
deployed address can be used anywhere an `Address` is expected. Any
`require_auth` for that address invokes `__check_auth` here, which demands at
least `threshold` valid ed25519 signatures from the configured signer set —
and signatures from *every* signer for changes to the account itself
(e.g. `set_threshold`).

> **Warning**: account contracts guard real funds and require rigorous review.
> This template is a learning/starting point, not an audited wallet.

## Develop

```sh
cargo test
stellar contract build
```

## Deploy to testnet

The constructor takes `signers` (ed25519 public keys) and `threshold`:

```sh
stellar contract deploy \
  --wasm target/wasm32v1-none/release/multisig.wasm \
  --source-account <your-identity> \
  --network testnet \
  -- --signers '["<HEX_PUBKEY_1>","<HEX_PUBKEY_2>","<HEX_PUBKEY_3>"]' --threshold 2
```
