# vesting

A token vesting contract with cliff + linear release schedule, generated by
[soroban-forge](https://github.com/soroban-forge-labs/soroban-forge) from the
`vesting` template.

## How it works

Tokens are deposited by an admin and become claimable by a beneficiary over
time according to a fixed schedule:

1. **Cliff period** — no tokens vest until a configurable duration (in seconds)
   has elapsed from initialization.
2. **Linear release** — after the cliff, tokens vest continuously at a constant
   rate over the remaining vesting duration.
3. **Claim** — the beneficiary calls `claim` to transfer any newly vested
   tokens to their address. Can be called multiple times.

## Develop

```sh
cargo test                 # run unit tests
stellar contract build     # build the deployable wasm
```

## Deploy to testnet

```sh
stellar contract deploy \
  --wasm target/wasm32v1-none/release/vesting.wasm \
  --source-account <your-identity> \
  --network testnet
```

Then initialize and fund:

```sh
stellar contract invoke \
  --id <CONTRACT_ID> \
  --source-account <ADMIN> \
  --network testnet \
  -- initialize \
  --admin <ADMIN_ADDRESS> \
  --token <TOKEN_ADDRESS> \
  --beneficiary <BENEFICIARY_ADDRESS> \
  --cliff_duration 604800 \
  --vesting_duration 2592000 \
  --total_amount 1000000

stellar contract invoke \
  --id <CONTRACT_ID> \
  --source-account <ADMIN> \
  --network testnet \
  -- fund
```

The beneficiary claims vested tokens:

```sh
stellar contract invoke \
  --id <CONTRACT_ID> \
  --source-account <BENEFICIARY> \
  --network testnet \
  -- claim
```
