# amm

A two-token constant-product automated market maker (`x * y = k`) with a 0.3%
swap fee, generated by
[soroban-forge](https://github.com/soroban-forge-labs/soroban-forge) from the
`amm` template.

## What it does

- `deposit` a pair of tokens to provide liquidity and receive pool shares
- `swap` one token for the other at the price set by the pool's reserves
- `withdraw` pool shares for a proportional slice of the reserves, including
  accrued fees

Pool shares are tracked internally; the two reserve tokens are any contracts
implementing the standard Soroban token interface (e.g. Stellar Asset
Contracts). The 0.3% swap fee stays in the pool, so the constant product `k`
grows as the pool is traded.

## Develop

```sh
cargo test
stellar contract build
```

## Deploy to testnet

The constructor takes the two reserve token addresses, `token_a` and
`token_b`:

```sh
stellar contract deploy \
  --wasm target/wasm32v1-none/release/amm.wasm \
  --source-account <your-identity> \
  --network testnet \
  -- --token_a <TOKEN_A_ADDRESS> --token_b <TOKEN_B_ADDRESS>
```

Once deployed, add liquidity with `deposit`, trade with `swap`, and remove
liquidity with `withdraw`.
