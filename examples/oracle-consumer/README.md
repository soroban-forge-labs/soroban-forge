# oracle-consumer

An oracle-consumer contract for Stellar/Soroban, generated by
[soroban-forge](https://github.com/soroban-forge-labs/soroban-forge) from the
`oracle-consumer` template.

## How it works

The contract is configured at deploy time with the address of an external
price oracle (e.g. [Reflector](https://reflector.network/)), the asset it
should price, and the number of decimals the oracle's price uses:

1. **`get_price`** — calls `lastprice` on the configured oracle contract and
   returns the latest price, panicking if the oracle has no price data.
2. **`convert`** — uses the latest price to convert an amount of the base
   asset into its value denominated in the oracle's quote asset.

The oracle interface (`lastprice(asset) -> Option<PriceData>`) matches the
shape published by Reflector, so this contract can be pointed at a real
deployed Reflector oracle by passing its contract address as `oracle`.

## Develop

```sh
cargo test                 # run unit tests against a mock oracle
stellar contract build     # build the deployable wasm
```

## Deploy to testnet

```sh
stellar contract deploy \
  --wasm target/wasm32v1-none/release/oracle_consumer.wasm \
  --source-account <your-identity> \
  --network testnet \
  -- \
  --oracle <ORACLE_CONTRACT_ADDRESS> \
  --asset <ASSET_SYMBOL> \
  --price_decimals 14
```

Then query the latest price or a converted amount:

```sh
stellar contract invoke \
  --id <CONTRACT_ID> \
  --network testnet \
  -- get_price

stellar contract invoke \
  --id <CONTRACT_ID> \
  --network testnet \
  -- convert \
  --amount 1000000000
```
